# 🎃 เปรม นมสด (Prem Nomsod) - Landing Page

Landing Page สไตล์คาเฟ่และร้านนมสดรอบดึก ออกแบบในธีม **Halloween Spooky Night Special Edition** สำหรับโปรเจกต์ LAB02

## 🌟 จุดเด่นของเว็บไซต์
- **ดีไซน์ Halloween Theme:** โทนสีดาร์กโกธิค ดำ-ม่วงนีออน-ส้มฟักทอง พร้อมแอนิเมชันค้างคาวบิน ผีลอย และใยแมงมุม
- **Responsive 100%:** รองรับหน้าจอคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน (Mobile-First)
- **เมนูอาหารและเครื่องดื่ม:** นำเสนอเมนูซิกเนเจอร์ (นมชมพูแม่มดมนตรา, ปังปิ้งช็อกโกแลตแดร็กคูล่า, ปังปิ้งไมโลภูเขาไฟ, ปังเย็นอสูรหิมะ ฯลฯ) พร้อมระบบฟิลเตอร์หมวดหมู่
- **มินิเกม Trick or Treat:** สุ่มคำทำนาย/คำสาปความหวานแบบอินเทอร์แอคทีฟ
- **เชื่อมต่อ Facebook & ข้อมูลร้าน:** ปุ่มเปิดไปยังเพจ Facebook [เปรม นมสด](https://www.facebook.com/premnomsod) และแผนที่พิกัดร้าน

## 🛠️ เทคโนโลยีที่ใช้
- **HTML5** (Semantic Structure)
- **Tailwind CSS** (via CDN)
- **Google Fonts:** Creepster & Prompt
- **Font Awesome 6** (Icons)
- **Vanilla JavaScript** (Interactions, Drawer Menu, Filter & Mini Game)
